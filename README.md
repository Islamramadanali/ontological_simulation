# ontological_simulation
لماذا دائمًا يوجد شيء وليس اللاشيء؟ الإجابة ببساطة: لأنَّ اللاشيء هو نقيض الشيء، والشيء هو كل ما يُمكن تمثيلُه أو تصوُّره، أمَّا اللاشيء فلا يمكن تمثيله أو تصوره لأننا إن مثلناه صار شيئًا.
يقولون أن هذا السؤال حيَّر الفلاسفة على مدار ألفي عام.. ربما حان الوقتُ لحسمِ المسألة. 
إسلام رمضان.
